# 交付前检查清单 · Delivery Checklist

## 产品一致性
- [ ] 产品颜色、形状、logo、包装文字与真实产品一致（逐帧抽查）
- [ ] 尺寸比例合理（手里拿着不会大得离谱）
- [ ] 没有错误的配件或不存在的功能

## 画面质量
- [ ] 9:16 竖屏，1080×1920（或客户要求）
- [ ] 人物手指、面部、动作无明显 AI 变形
- [ ] 前 3 秒有清晰钩子
- [ ] 无水印（工具水印需已按套餐去除）

## 文案与合规
- [ ] 卖点全部来自客户确认的信息
- [ ] 没有医疗 / 疗效 / 「保证」「第一」等绝对化用语
- [ ] CTA 温和，无虚假紧迫感（如虚假「仅剩 3 件」）
- [ ] 按平台要求标注 AI 生成 / 广告（客户投放前提醒对方）
- [ ] 字幕无错别字，语言地道（英文可让 AI 校对一遍）

## 音频
- [ ] 配音清晰、语速自然
- [ ] 背景音乐有商用授权（或用平台曲库）
- [ ] 音量平衡，字幕与配音同步

## 打包
- [ ] 文件命名：`{品牌}_{产品}_{风格}_{序号}.mp4`，例 `Acme_HandCream_unboxing_01.mp4`
- [ ] 附 `scripts.csv`（id 与视频序号对应）
- [ ] 附 `README.txt`：数量、规格、修改说明、使用建议
- [ ] 上传网盘（Google Drive / Dropbox / 百度网盘），检查链接权限可访问

## 交付后
- [ ] 24 小时内跟进：「有需要调整的吗？」
- [ ] 询问投放数据（哪条效果好），用于下一批优化
- [ ] 提议下一款产品或月度包（不强推）
