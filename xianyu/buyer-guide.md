# 买家上手指南（3 步）

## 第 1 步：打开工具
解压压缩包 → 进入 `app` 文件夹 → 双击 `index.html`。
👉 请用 **Chrome / Edge / Safari** 打开，不要在微信 / QQ 里直接打开。

## 第 2 步：生成脚本
1. 填「产品名称」，如 `Hand Cream`（做海外素材建议英文名）
2. 选品类、语言（English / 中文）、数量（1–20）
3. 勾选风格 → 点 **✨ 生成脚本** → 点 **⬇ 下载 CSV**
4. 用 Excel / WPS / Google 表格打开 CSV

## 第 3 步：变成视频
1. 打开 `templates/prompts/higgsfield-scene.md`，把 CSV 里的 scene1–scene4 交给 ChatGPT 转成画面提示词
2. 在 Higgsfield / Kling 等工具里**先出 1 条试片**，确认产品没变形
3. 用剪映 / CapCut 加配音（voiceover 列）和字幕（text_on_screen 列）

## 下一步
- 想系统学习：看 `README.zh-CN.md`
- 想找客户：看 `templates/sop/from-zero.md`
- 交付前：对照 `templates/sop/delivery-checklist.md`

> 提醒：本工具帮你提高脚本整理效率，不保证收入。生成内容请人工审核、如实宣传。
